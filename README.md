# easy-pcb-order — prototype KiCad 9/10

Plugin pour un projet comportant plusieurs cartes indépendantes dans **un seul fichier `.kicad_pcb`**. Il détecte les contours fermés `Edge.Cuts`, demande un nom, un nombre de couches et la qualification « front panel » pour chacun, puis propose JLCPCB, PCBWay et un export générique pour un autre fabricant. Chaque carte reçoit son propre `gerbers.zip` avec fichiers Gerber et perçages ; les cartes non marquées « front panel » reçoivent aussi `bom.csv` et `positions.csv` si le preset les demande. Il ne modifie jamais le PCB d'origine.

## Installation

1. Décompresser l'archive. Copier le dossier `easy_pcb_order` (qui contient `__init__.py`) dans le dossier des plugins de KiCad. Sur macOS, ouvrir **Éditeur de PCB → Outils → Plugins externes → Révéler le dossier des plugins dans le Finder**. Sinon, utiliser `~/Documents/KiCad/<version>/scripting/plugins/` et créer `plugins` si nécessaire.
2. Redémarrer l'Éditeur de PCB ou actualiser les plugins externes. Lancer **Outils → Plugins externes → easy-pcb-order**.
3. Enregistrer le PCB avant l’export. Suivre les six étapes : (1) un ou plusieurs designs, (2) confirmer chaque carte avec son aperçu (contours, découpes, pistes et composants), (3) choisir les couches et indiquer les front panels à côté des aperçus, (4) nommer les designs à côté de leurs aperçus, (5) attribuer les références LCSC une empreinte à la fois, (6) choisir JLCPCB, PCBWay ou un autre fabricant.
4. À l’étape composants, les références de même famille (R, C, D…), valeur, empreinte et technologie d’assemblage sont regroupées. Le plugin affiche toutes leurs références dans sa fenêtre, tente de les mettre en évidence dans KiCad et centre la vue sur la première. Cliquer sur **Catalogue JLCPCB** puis saisir `C…` manuellement (aucun compte API nécessaire). **Rechercher LCSC** nécessite un accès partenaire. **Ne pas assembler** exclut le groupe. Les numéros déjà attribués sont repris lorsque la correspondance est unique. Une liste finale de **tous les composants** permet de corriger une référence isolée par double-clic, même si elle faisait partie d’un groupe. Les choix sont enregistrés dans `<projet>.kicad_pcb.parts.json`, près du PCB.
   La colonne **Stock (source et date)** affiche « Non vérifié » par défaut. Sélectionner une ligne, cliquer sur **Consulter / renseigner le stock**, choisir JLCPCB (stock d’assemblage) ou LCSC (stock distributeur), consulter le catalogue ouvert dans le navigateur et saisir la quantité affichée. Ce relevé manuel est conservé par numéro de pièce dans `<projet>.kicad_pcb.stock.json` ; il n’est pas actualisé automatiquement et doit être vérifié avant commande. La quantité LCSC ne garantit pas le stock d’assemblage JLCPCB.
5. Contrôler chaque fichier Gerber et le placement, notamment la polarité et l’orientation, dans le visualiseur du fabricant avant commande.

## Limites et contrôles

- Les contours extérieurs et les découpes intérieures `Edge.Cuts` peuvent être formés de segments, arcs, rectangles ou cercles. Les contours intérieurs sont conservés dans le fichier de fabrication de leur carte et ne sont pas comptés comme des PCB distincts. Les contours ouverts, ramifiés et les îlots à l’intérieur d’une découpe sont refusés. Vérifier chaque Gerber dans un visualiseur avant commande.
- La détection ne sait pas déduire les noms « UI », « Main » et « front panel » : l'utilisateur les assigne en regardant les dimensions et l'ordre spatial.
- Les cartes du fichier source partagent initialement la même pile de couches. Le plugin extrait chaque carte, puis peut réduire **sa copie temporaire** (par exemple une face avant à 2 couches dans un fichier source à 4 couches). La réduction est refusée si le design utilise des couches internes supprimées ou si un via borgne ou enterré devient invalide. Les vias traversants restent autorisés en deux couches. Le plugin vérifie la pile enregistrée avant les Gerbers. Il ne peut pas créer davantage de couches que le fichier source.
- Le profil JLCPCB exporte une BOM avec numéro LCSC et un placement `Designator/Mid X/Mid Y/Rotation/Layer`. Le profil PCBWay exporte une BOM détaillée (référence, valeur, boîtier, type, numéro distributeur) et un placement `RefDes/X/Y/Rotation/Side`. Le profil autre fabricant exporte des colonnes génériques. Vérifier la compatibilité dans le formulaire de commande du fabricant. Les corrections de rotation propres aux machines ne sont pas automatisées.
- Si le dossier `<projet>-fabrication` existe, l'export s'arrête pour ne pas écraser une commande précédente. Déplacer ou renommer ce dossier pour relancer.
- Exige l'installation `pcbnew` et `wxPython` livrée avec KiCad et un `kicad-cli` accessible dans le PATH. Prototype non exécuté dans KiCad dans cet environnement : faire un premier essai sur une copie du projet.

## Accès aux catalogues

- JLCPCB fournit une API officielle Components, accessible après inscription et approbation sur https://api.jlcpcb.com/ . Le plugin propose pour l’instant la recherche dans le navigateur et la confirmation manuelle du numéro de pièce ; l’API JLC ne peut pas être intégrée de façon fiable sans paramètres de compte et documentation d’accès.
- LCSC publie une API de recherche partenaire : https://www.lcsc.com/docs/openapi/index.html . Après obtention des accès auprès de LCSC, lancer KiCad depuis un environnement définissant `LCSC_API_KEY` et `LCSC_API_SECRET`. Le plugin signe les requêtes de recherche selon la documentation officielle et affiche les résultats reconnus. Ces secrets ne sont pas enregistrés. Les réponses exactes de l’API ne sont pas vérifiées sans compte partenaire : la saisie manuelle reste disponible.
- Vérifier chaque correspondance avec la fiche technique et le modèle d’assemblage JLCPCB. Une disponibilité chez LCSC n’établit pas à elle seule la disponibilité de la pièce dans le service PCBA de JLCPCB.
- Le regroupement est conservateur mais la même valeur et empreinte ne suffisent pas à prouver la compatibilité électrique, notamment pour les LED (couleur, polarité, luminosité), les condensateurs (tension, diélectrique) et les résistances (puissance, tolérance). Vérifier et corriger la liste finale avant l’export.
